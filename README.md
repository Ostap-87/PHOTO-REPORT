# ФотоОтчёт

Своё приложение для фотоотчётов по ТЗ заказчика: замена облачным сервисам фотофиксации вроде FixOmni.
Работает на компьютере (Mac, Windows, Linux), фото никуда не отправляются.

## Что умеет

**Модуль 1. ТЗ и исполнение.**
- Загружаете ТЗ заказчика (Word, PDF, Excel, CSV, текст): слева видно оригинал, справа «совершенная копия».
- В копии каждый пункт ТЗ — карточка:
  - статус: *Не начато*, *Выполнено*, *Предоставлено*, *Исполнено*, *Не требуется* (с датой);
  - комментарий;
  - места для фото под пунктом.
- Нажатие на пункт подсвечивает его в оригинале.
- Пункты можно поправить, добавить или удалить вручную, можно работать и вовсе без файла ТЗ.

**Реестр подтверждений (анализ ТЗ ИИ).**
- Кнопка «Составить реестр (ИИ)»: модель Claude читает всё ТЗ строго по заданию `config/registry_prompt.md`
  и выписывает пункты, по которым нужно приложить подтверждение, — что именно и в каком виде (столбцы
  «Пункт ТЗ, Раздел, Наименование, Описание, Что приложить, Комментарий») и отдельно «Требуют уточнения».
  Два шага: реестр, затем обязательная повторная сверка всего ТЗ.
- Строки реестра становятся папками: фото и скриншоты, файлы (документы, видео) и ссылки на размещения.
- Готовый реестр можно загрузить из Excel; выгрузка — «Реестр подтверждений» в Excel в том же виде.
- Нужен ключ API Anthropic (console.anthropic.com → API Keys): кнопка «ИИ» вверху справа. Ключ хранится
  только на компьютере (`~/Library/Application Support/ФотоОтчёт`); текст ТЗ при анализе отправляется в
  Anthropic и оплачивается по их тарифу (ориентир — около 1 $ за ТЗ на 100 тыс. знаков). Фото не отправляются.
- ТЗ в виде одной таблицы «№ | Раздел | Требования» с автонумерацией Word разбирается до каждого подпункта.

**Модуль 2. Фото.**
- Загружаете большой массив фото: сразу сотни, JPG, PNG, HEIC с iPhone, TIFF, WEBP или ZIP-архивы.
- Папки создаются автоматически из пунктов ТЗ.
- Приложение само распознаёт, что на фото, и раскладывает их по папкам.
  - Уверенно не узнало — оставляет фото в «Неразобранном» и показывает подсказки, куда его скорее всего положить.
  - Фото, которые вы переложили или подтвердили (✓), служат примерами: остальные раскладываются точнее.
  - Подсказка у пункта («что на фото», например «банкетные столы, белые скатерти») тоже уточняет раскладку.
- Улучшение там, где нужно: тёмные, пересвеченные, блёклые, шумные, смазанные кадры исправляются автоматически.
  Варианты: *где нужно*, *все фото*, *не улучшать*. Исходник не меняется никогда; «до / после» видно в просмотре.
- Галочка **«Замазывать лица»**: размытием или пикселями. Можно включить для всего проекта или для отдельного фото.
- Дубли (почти одинаковые кадры) и кадры «переснять» (слишком тёмные или смазанные) собираются в отдельные отборы.

**Отчёты:** Word, PDF, Excel, ZIP-архив по папкам или настоящие папки на диске (`Документы/ФотоОтчёт/Папки`);
по реестру — раздел, «что приложить», замечание анализа, ссылки и файлы у каждого пункта.

## Установка на Mac

1. Нужен Python 3.11 или новее. Если его нет, скачайте с https://www.python.org/downloads/macos/ («macOS 64-bit universal2 installer»).
2. Скачайте этот репозиторий (на GitHub: **Code → Download ZIP**) и распакуйте, например в «Документы».
3. В Терминале выполните:
   ```bash
   bash ~/Documents/PHOTO-REPORT-main/install_mac.command
   ```
   Это займёт несколько минут.
4. Откройте **«ФотоОтчёт»** значком на рабочем столе (или из Launchpad / Finder → «Программы»). Чтобы держать
   под рукой, перетащите в Dock.

Обновить уже установленный ФотоОтчёт (проекты и библиотеки сохраняются):

```bash
cd ~/Documents/PHOTO-REPORT-main && curl -fsSL https://codeload.github.com/Ostap-87/PHOTO-REPORT/tar.gz/refs/heads/main \
  | tar -xzf - --strip-components=1 && bash install_mac.command
```

При первом запуске приложение само скачает модель распознавания (~230 МБ, один раз, в `~/.cache/photo-report/models`;
если huggingface.co недоступен — с зеркала hf-mirror.com, своё зеркало — переменная `HF_ENDPOINT`).
Проекты хранятся в `~/Documents/ФотоОтчёт/Проекты`. Папку с приложением после установки не переносите.

Если pypi.org отвечает медленно (Китай, часть сетей в России), установщик сам берёт библиотеки с зеркала
(Цинхуа или Alibaba); своё зеркало: `PIP_INDEX_URL=<адрес> bash install_mac.command`.

Без окна, в браузере: `start_mac.command` (откроется http://127.0.0.1:8010).
Windows: `start_windows.bat`. Linux и разработка:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m uvicorn app.server:app --port 8010
.venv/bin/python -m pytest -q
```

## Как пользоваться

1. **Проекты → Новый проект**: название и заказчик.
2. **ТЗ и исполнение**: перетащите файл ТЗ. Пункты станут карточками, а на вкладке «Фото» появятся папки.
3. **Фото**: перетащите фото или ZIP прямо в окно. Сверху — «Улучшение» и «Замазывать лица».
   Идёт обработка, затем раскладка. Дальше:
   - **Неразобранное**: нажмите подсказку под фото или перетащите фото в папку слева;
   - **Разложено автоматически**: нажмите ✓, если папка верная (или выделите несколько и «Подтвердить»).
4. **ТЗ и исполнение**: отметьте статус пунктов и допишите комментарии. Фото можно перетаскивать между пунктами
   и добавлять в пункт кнопкой «+ фото».
5. **Отчёт**: выберите формат и нажмите кнопку. Файл попадёт в «Загрузки».

## Настройки

`config/settings.yaml`:
- `threshold` — насколько смело раскладывать фото;
- `margin` — отрыв лучшего пункта от второго;
- `auto_download_models` — скачивать ли модель при первом запуске.

Устройство программы — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Что внутри

- Python, FastAPI и одна веб-страница; на Mac и Windows — своё окно (pywebview).
- Распознавание — CLIP (ViT-B/32) на onnxruntime. Тексты пунктов ТЗ понимаются по-русски
  (многоязычная модель `clip-ViT-B-32-multilingual-v1`). Видеокарта и интернет после первой загрузки не нужны.
- Улучшение — OpenCV: экспозиция, локальный контраст, баланс белого, шумоподавление, резкость.
- Лица — детектор YuNet (OpenCV Zoo, лицензия Apache 2.0).
