ДоПосле

Анализ ТЗ искусственным интеллектом

Реестр подтверждений составляет модель Claude (Anthropic) строго по вашему заданию — файл config/registry_prompt.md. Для этого нужен ключ API: создайте его на console.anthropic.com (раздел API Keys) и вставьте сюда.

Ключ хранится только на этом компьютере (). Текст ТЗ при анализе отправляется в Anthropic; оплата — по тарифу Anthropic за каждый анализ. Фото никуда не отправляются.
